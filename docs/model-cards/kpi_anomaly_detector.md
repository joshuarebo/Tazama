## Limitations

- Measured against the seeded incident windows, which are the only ground truth available; precision is understated because a real degradation outside a labelled window counts as a false positive.
- A robust z-score is unconditional: it says 'unusual', never 'bad'. A planned maintenance window looks exactly like a fault to it, which is why suppression lives in correlation and not here.
- Needs roughly two weeks of history per cell before the hour-of-week baseline is meaningful; it falls back to coarser bins below that.

## Ethical and operational notes

- The model informs a human. It executes nothing: no runbook, no customer
  message, no network change follows from its output (PRD §9, §11).
- No subscriber identifier reaches training. Features are cell-level
  aggregates; complaint counts are normalised by `cell.subscribers_est`.
- Retraining is a new version, never an edit. The registry refuses to
  overwrite a version, because the data hash recorded against it is a
  promise about which data produced which artifact.
